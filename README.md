# РКО CRM — Telegram Mini App

CRM для лидов по РКО, МФО и картам. Повторяет логику ваших Google-таблиц и открывается кнопкой в боте.

- **Сегодня** — рабочий список на день: напоминания, «нужна ЦД», «ждут засчёта — пинать партнёрку», заявки, лиды без движения. По 5 самых денежных в блоке, «Все →» открывает полный список.
- **Лиды** — поиск, фильтры (нужна ЦД, ждут засчёта, заявки, напоминания, без движения, этапы) и сортировки (деньги в работе, заработали, давно не трогали).
- **Карточка лида** — этап в один тап, «Написать» в Telegram, следующий шаг с напоминанием (сегодня / завтра / 3 дня / неделя), офферы: тап → шторка со статусами, «＋ Оффер» → сетка свободных офферов. Отказы и дубли свёрнуты. История: кто и что менял.
- **Статистика** — засчитано за 7 / 30 дней / месяц / всё время, график по дням, средний чек лида, конверсия лид → деньги, топ офферов с конверсией, партнёрские сети, источники, воронка, отчётный лист.
- **Бот** — каждый день в 9:00 МСК сводка: вчерашние засчёты, деньги за неделю, напоминания, ЦД, кого пинать. По понедельникам админам — бэкап (JSON + 2 таблицы CSV). Бэкап можно запросить в любой момент: «Ещё» → «Бэкап и выгрузка».
- **Расчёт** (формула «Отчётного листа»): доход = засчитанные ставки; налог 7% от дохода; доля партнёра 20% от (доход − налог); чистая = доход − партнёр − налог − затраты − выплачено лиду. Меняется в «Ещё» → «Расчёт».
- **Быстрый ввод**: шторка оффера не закрывается — статус, ставка, затраты частями (+20 / +50 / +100 / +500 / своя), шаблоны комментариев (ЛК Дамира, Провели…, Маскировка), срок по офферу (завтра / 5 дней маскировка / неделя / дата). Выплата лиду частями, телефон, шаблоны сообщений лиду.
- **На «Сегодня»** — кнопки «ЦД ✓», «засчитано ✓», «счёт ✓» прямо в списке, план на месяц с прогрессом, сроки по офферам.
- **Лиды из бота**: перешли боту сообщение человека, отправь контакт или напиши `@ник ФИО телефон` — лид создастся, бот ответит кнопкой «Открыть лида». Дубли по нику, Telegram-аккаунту и телефону ловятся. Бот подключается сам при первом входе админа (вебхук `/api/tg`, секрет выводится из токена).
- **Выплаты от сетей**: по каждой партнёрской сети — засчитано, получено, недоплатили, с точностью до оффера. Пришёл платёж — отмечаешь закрытые офферы, вносишь сумму, CRM показывает расхождение. «Начальная сверка» одной кнопкой отмечает засчёты из таблицы. Недоплата — в «Сегодня» и в утренней сводке админам.
- **Этап сам подтягивается**: взяли первый оффер — «В работе», первый засчёт — «Докрутка».

Роли: **админ** видит всех лидов, правит каталог и расчёт, делает импорт. **Менеджер** видит только своих лидов.

## Стек

- Фронт: чистый HTML/JS в `public/`, подхватывает тему Telegram.
- Бэкенд: логика в `lib/`, запускается на **Cloudflare Workers** (`worker/index.mjs`, база Workers KV) или на Netlify (`netlify/functions/api.mjs`, база Netlify Blobs).
- Доступ: подпись Telegram `initData` проверяется на сервере, плюс белый список Telegram ID.

## Запуск на Cloudflare (основной вариант)

1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Import a repository** → подключи GitHub → выбери этот репозиторий и ветку с кодом. Остальные поля оставь по умолчанию: деплой сделает `npx wrangler deploy`, а база KV создастся сама.
2. В созданном воркере: **Settings → Variables and Secrets → Add** → тип **Secret**, имя `BOT_TOKEN`, значение — токен бота.
3. Админы и менеджеры задаются в `wrangler.toml` (`ADMIN_IDS`, `MANAGER_IDS`), любое изменение выкатывается автоматически после пуша.
4. В BotFather: `/mybots` → бот → **Bot Settings → Menu Button** → адрес воркера (`https://ryzhikov.<аккаунт>.workers.dev`).

## Запуск на Netlify (запасной вариант)

### 1. Бот
1. Открой [@BotFather](https://t.me/BotFather) → `/newbot` → придумай имя → получи **токен**.
2. Узнай свой Telegram ID, например у [@userinfobot](https://t.me/userinfobot).

### 2. Деплой на Netlify
1. Зайди на [app.netlify.com](https://app.netlify.com) → **Add new site → Import from Git** → выбери этот репозиторий. Настройки сборки подтянутся из `netlify.toml`.
2. **Site configuration → Environment variables**, добавь:
   | Переменная | Значение |
   |---|---|
   | `BOT_TOKEN` | токен от BotFather |
   | `ADMIN_IDS` | твой Telegram ID (несколько — через запятую) |
   | `MANAGER_IDS` | ID менеджеров через запятую (можно пусто) |
3. Нажми **Deploy**. Получишь адрес вида `https://имя.netlify.app`.

### 3. Кнопка в боте
В BotFather: `/mybots` → твой бот → **Bot Settings → Menu Button** → вставь адрес сайта.
Готово: открываешь бота, жмёшь кнопку, CRM внутри Telegram.

### Как добавить менеджера
Менеджер открывает бота и видит «Нет доступа» вместе со своим ID. Добавляешь этот ID в `MANAGER_IDS` на Netlify и делаешь **Deploys → Trigger deploy**.

## Импорт лидов из таблиц

Вкладка «Офферы» → «Импорт лидов» → JSON-файл. Лид с тем же Telegram обновляется, остальные создаются. Формат:

```json
{ "leads": [
  { "telegram": "@Diman0004", "fio": "Давыдов Дмитрий Евгеньевич", "stage": "offers", "payout": 0,
    "offers": {
      "alfa":   { "status": "paid",   "amount": 15500, "cost": 0,    "comment": "Провели 2300" },
      "otp":    { "status": "opened", "amount": 8200,  "cost": 1380 },
      "zaymer": { "status": "paid",   "amount": 3300,  "cost": 20,   "comment": "ЛК Дамира" }
    } }
] }
```

ID офферов (`alfa`, `otp`, `zaymer`…) смотри в `lib/offers.mjs`. Этапы: `new`, `in_work`, `offers`, `closed`, `lost`. Статусы: `none`, `applied`, `opened`, `done`, `paid`, `rejected`, `exists`.

## Локальная разработка

```bash
npm install
npm test                                 # тесты API и проверки подписи
echo "DEV_MODE=1" > .dev.vars && npx wrangler dev   # открыть в браузере без Telegram (вход как админ)
```

`DEV_MODE=1` никогда не ставь на продакшене: он пускает без авторизации.
