# Ryzhikov Academy · «Спуск в логово»

Продающий сайт академии: дракон спускается через 9 залов, в каждом своя часть программы.

## Структура
- `index.html` — все залы и тексты
- `css/style.css` — стиль
- `js/dragon.js` — процедурный дракон (canvas)
- `js/app.js` — сценарий скролла, врата, калькулятор. **Ссылка для кнопок — `CONFIG.cta` в начале файла**
- `assets/img` — фото и скрины, `assets/vendor` — GSAP, ScrollTrigger, Lenis

## Деплой на Netlify
Перетащи папку проекта в Netlify Drop (app.netlify.com/drop) или подключи этот репозиторий — сборка не нужна, `netlify.toml` уже настроен.
