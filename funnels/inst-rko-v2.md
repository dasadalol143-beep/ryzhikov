## Служебные блоки

### СТОП (стартовое условие `стоп;stop;/stop`, полное совпадение)
> Понял, больше не пишу. Передумаешь, напиши «видео».

Флаг в калькуляторе: `stopped = 1`. Блок без выходящих переходов. Проверь тестом, что таймеры после него не стреляют.

### Уведомление менеджеру (одно на шаг, меняется только название шага)
```
text = "🔥 #{full_name} @#{tg_username} id #{client_id} | шаг: ВИДЕО | ответь сейчас"
manager = <id чата менеджеров>
tg_send_message(#{manager}, text)
```

### Ветка Б (старт `callback`)
Поставь полное совпадение вместо «игнорируя ошибки». В первом сообщении: «2 года назад… вейпшоп за 50–70к». Блок «Раз ты забрал видео» подключи **только** к уведомлению после клика, не к таймеру из «ты так и не забрал».
