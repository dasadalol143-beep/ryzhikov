# Команда Рыжикова — CRM отдела продаж (Telegram Mini App)

Отдельное приложение от РКО CRM. Заменяет таблицы «РнП», «Окна для звонков», CRM и «Зарплатную ведомость РКО» и живёт по регламенту отдела продаж.

## Дизайн
Один спокойный стиль: тёплый светлый фон, белые карточки, один акцент (кобальт), графитовая шапка с фоном `public/hero.webp`, линейные иконки вместо эмодзи, своя тёмная тема (переключается вместе с Telegram). Цвет несёт только смысл: зелёный — свободно/продажа, красный — долг/НДЗ, жёлтый — в работе.

## Роли
| Роль | Что видит и делает |
|---|---|
| Собственник (Петя) | всё + ведомость + команда + настройки + импорт |
| РОП (Андрей) | всё + ведомость (вносит чистую, верифицирует), добавляет менеджеров, лидорубов и траферов |
| Менеджер ОП (Дима, Тема) | все клиенты, свои созвоны, отчёты, дожим. Ведомость **не видит** |
| Лидоруб | заводит лидов, отмечает ЛМ, записывает на созвон в свободное окно диагноста |
| Трафер (Матвей) | приводит лидов из своих источников: заводит с обязательной анкетой (возраст, откуда, знаком ли с темой, чем занимается, что хочет, комментарий), ставит в окна диагностов, видит, кто из его лидов дошёл и купил. Лиды — по `trafferId`, уведомления о НДЗ/переносе/продаже приходят ему. В ведомости процента нет |

## Защита от потери лидов
- Одна база: карточка, таблица, РнП, ведомость и бот показывают одного и того же клиента — слив везде слив.
- «Зависли» — папка и блок на «Сегодня»: любой незакрытый лид без следующего шага (созвон не отмечен, итог не заполнен сутки, новый 2+ дня без записи, дожим заброшен 4+ дня, нет ответственного). Утром бот присылает каждому его зависших, руководству — всех.
- Итог после созвона: бот напоминает диагносту 3 раза (через 30 минут, 3 часа, утром в 10:00), потом пишет РОПу и собственнику.
- Удаление — только в корзину («Ещё → Корзина», восстановление в один тап). Каждое утро собственнику приходит полный бэкап базы в Telegram.
- Дубли по нику/телефону не создаются; клиента, которого взял МОП, меняют только он, РОП и собственник.

## Экраны
- **Сегодня → «Что сделать сейчас»** — задачи по порядку с цифрами, тап — сразу к нужным клиентам. Лидорубу — его лиды по этапам, графики «завёл / записал» за 14 дней и продажи с его лидов.
- **Клиенты → Таблица** — вся CRM как раньше в Google-таблице (клиент, заявка, статус, созвон, диагност, лидоруб, источник, сумма, запрос, дальнейшие шаги, телефон), фильтры по человеку и папке; «+ Добавить строками» — вставить пачку лидов «Имя @ник +7… что известно».
- **Ещё → Как пользоваться** — шаги для каждой роли.
- **Сегодня** — у каждой роли свой: созвоны по времени с кнопками «Пришёл / НДЗ», долги по отчётам, дожим на сегодня (3 касания → «Игнор» автоматически), новые лиды без созвона, у РОПа — команда за день и оплаты на проверку, план месяца.
- **Клиенты** — поиск и фильтры (новые, созвон назначен, нет отчёта, дожим, думают, оплатили, отказ по банкам…), фильтр по человеку. Карточка: статус в один тап, данные, чат, созвоны и отчёты, история.
- **Окна** — вместо таблицы «Окна для звонков». Любой из команды открывает диагносту окна: «Тёма, вт–пт, 18–21» (можно сразу несколько дней и несколько интервалов). Каждый диагност — карточка со слотами по часу: зелёный — свободно (тап → выбрать клиента или завести нового и записать), серый — созвон (тап → карточка). Созвон вне окна подсвечен. Запись из карточки клиента тоже предлагает свободные слоты окна.
- **Кто меняет клиента** — пока диагност не назначен, лид общий (лидоруб заводит, отправляет ЛМ, записывает). Взял МОП — менять карточку (статусы, созвоны, итог, данные, удаление) может только этот МОП, РОП и собственник; в приложении, боте и через ИИ. Остальные видят «только просмотр» и могут оставить комментарий. Свою только что сделанную запись можно отменить 15 минут.
- **Карточка клиента** — сверху полоса пути (Лид → Созвон → Итог → Решение → Закрыт) и блок «Что делать сейчас» с одной-двумя кнопками: записать на созвон → «Пришёл / Не пришёл» → «Заполнить итог» → «Что решил клиент» (Оплатил, Предоплата, Думает, Перенос, Отказы) → дожим. Данные и ручная смена статуса свёрнуты ниже. Удалить клиента может тот, кто его ведёт, и руководство (уходит в корзину).
- **Без дублей** — один @ник и один телефон = один клиент (в любом регистре, со ссылкой t.me). Повторная запись на то же время не создаёт второй созвон, сдвиг на полчаса — перенос того же созвона. Старые дубли по нику склеиваются сами; похожие по имени — кнопка «Склеить» в карточке.
- **РнП** — считается сам (обновляется каждые 30 секунд и при возврате в приложение). Любая цифра в таблице кликабельна — список клиентов, из которых она сложилась; цифра не сходится — открыл клиента и поправил.
- **РнП (подробно)** — считается сам по карточкам: лиды, назначено, проведено, CR, продажи, предоплаты, отказы по банкам, потенциал. Периоды: сегодня/вчера/7 дней/пол-месяца/месяц/прошлый/всё. Вкладки «Лидоруб» и «По дням», блок «Где течёт».
- **Ещё → Ведомость** (только собственник и РОП) — формулы из таблицы: комиссия = тариф − чистая, налог 7% от чистой, МОП 10% / РОП 3% / лидоруб 2% от (чистая − налог), «остаётся чистыми». «Оплатил» в карточке сам создаёт черновик оплаты.

## Бот — пиши как человеку
- `созвон завтра в 15 к Тёме @ivan Иван` — запишет (нет клиента — заведёт), диагност сразу получит «🆕 Новый созвон». Время занято — откажет и покажет свободные окна. Под ответом — «Отменить».
- Несколько созвонов одним сообщением: `завтра: Теме в 18 с Антоном @anton, в 19 с Мишей; Диме на 20:00 Олег +7900…` — каждый в CRM, каждому менеджеру уведомление, пересечения пропускаются с объяснением, кнопка «Отменить всё».
- Созвон уже был, а в CRM нет: `сегодня у Димы в 14:00 был созвон с @ivan` — внесёт и спросит «пришёл / НДЗ».
- Статус одной строкой: `@ivan пришёл`, `@ivan ндз`, `@ivan оплатил 100к`, `@ivan думает 80к`, `@ivan отказ банки`, `@ivan игнор`.
- `окна завтра`, `окна в пятницу у Димы`, /windows — окна диагностов, свободные и занятые слоты.
- `окна Тёме завтра с 18 до 21`, `у Димы окно в пятницу 12-14 и 18-20`, `закрой окна Теме завтра` — открыть/закрыть окна; диагност получит сообщение. Запись вне окна бот внесёт, но пометит.
- /today, /tomorrow — свои созвоны и задачи. /links или `ссылки 100` — ссылки на оплату.
- Переслал боту сообщение клиента — лид заведён, кнопка «Записать на созвон».

## ИИ в чате и голосовые
- **Говори как с человеком.** Чёткие команды (`@ivan ндз`, `созвон завтра в 15 к Тёме…`) бот разбирает сам и бесплатно. Всё остальное и любые вопросы уходят в ИИ (Claude Haiku 5.5). Он помнит последние 8 сообщений за 6 часов, так что «отмени его» и «на то же время» понимает.
- **ИИ умеет:** записать один или несколько созвонов, перенести, отменить, поставить статус, сохранить отчёт после диагностики своими словами, добавить комментарий в карточку, завести лида, передать сообщение человеку или всем, ответить по РнП за любой период, по карточке клиента и спискам («кто думает у Димы»), написать текст для дожима.
- Пишет в базу тем же кодом, что и обычные команды: проверяет окна, рассылает уведомления, даёт кнопку «Отменить». Ведомость и зарплаты ИИ не видит.
- **Голосовые и кружки** расшифровывает Whisper в Cloudflare Workers AI (бесплатный дневной лимит) и дальше обрабатывает как текст.
- **Деньги:** модель по умолчанию — `claude-sonnet-5-5` (понимает сложные просьбы и сама правит CRM), сообщение ≈ $0.01–0.03. Потрачено 80% месячного бюджета — до 1-го числа бот сам переходит на дешёвый `claude-haiku-5-5` (≈ $0.002). Ограничения: 300 сообщений в день (`AI_DAILY_LIMIT`) и $30 в месяц (`AI_MONTHLY_BUDGET`); упёрлись — ИИ молчит, команды работают. Жёстко задать модель — переменная `AI_MODEL`.
- **Что ИИ умеет менять:** записать/перенести/отменить созвон («мой лид с 21:00 перенеси на 16:00»), статус, отчёт, комментарий, данные карточки (имя, ник, телефон, договорённости, сумма), удалить клиента в корзину, окна, сообщение команде. Права те же, что в приложении.
- **Проверка:** `/ai` у собственника и РОПа показывает, принят ли ключ, сколько потрачено за месяц и прогноз.
- Включение: Cloudflare → воркер → **Settings → Variables and Secrets → Secret** `ANTHROPIC_API_KEY`. Нет секрета — всё работает как раньше, бесплатно.

## Передача лидов между диагностами
- **Передать своего:** в карточке «Передать другому диагносту» — открытые созвоны и «ведёт» уходят новому, время то же. Новый диагност, прежний и лидоруб получают уведомление. Занято у нового в это время — предупредит.
- **Забрать себе:** чужого лида, с которым его диагност ещё не работал (ни созвона, ни отчёта, ни касаний), — сразу. Если работал — запрос ему в бот с кнопками «Отдать / Оставить себе» (решает он или руководство). Лидоруб забирать не может.
- **Ботом/ИИ:** «забери @ivan себе», «передай @ivan Диме».

## Записи созвонов
- **Где хранятся:** в Telegram через нашего бота (бесплатно, файлы до 2 ГБ, без публичных ссылок). В базе — только `file_id`, который работает лишь с токеном нашего бота.
- **Выгрузить:** в карточке «Выгрузить созвон». До 20 МБ — прямо из приложения; больше — «Отправить через бота»: открывается чат, бот ждёт файл 3 часа и сам привязывает его к лиду. После «Пришёл» бот час подсказывает клиента («это запись к …?») — в один тап. Файл без контекста — бот спросит, к какому клиенту; каждый файл ждёт отдельно, ничего не затирается. Отчёт в подписи к файлу тоже сохраняется.
- **Архив:** каждая запись сразу копируется в закрытый канал-хранилище (Петя подключает командой `/storage`: создать канал → добавить бота админом → переслать боту сообщение из канала). Пока канала нет — копия тихо падает Пете в личку.
- **Скачать:** «Получить» — бот присылает файл в личку тому, кто нажал. Доступ — у всех, кто в команде. Каждое скачивание пишется в историю карточки; больше 30 за час нельзя; 10 за час — сигнал Пете в ленту.
- **Удалить:** только Петя, и только скрыть — копия в архиве остаётся. При склейке дублей записи переезжают.
- **Задача:** проведённый созвон без записи 3 дня — «Выгрузи запись созвона» на «Сегодня», папка «Без записи созвона».

## Уведомления (бот + 🔔 лента в приложении)
Новый созвон и перенос → диагносту. НДЗ → лидорубу и руководству. Продажа → руководству, диагносту и лидорубу с процентом плана. Отказ по банкам → руководству и лидорубу. Комментарий в карточке → всем, кто ведёт клиента. Автору действия не пишем.

## Выплаты команде
- МОПу Петя платит сразу после продажи, РОПу и лидорубу — по понедельникам. У каждой оплаты в ведомости видно, кому уже выплачено (метки МОП / РОП / Лидоруб; всё выплачено — строка зелёная, как в таблице).
- «Ещё → Выплаты»: кому сколько должны и за кого (раскрыть «За что»), кнопка «Выплатил» — получатель сразу получает в бота сумму и список оплат. Ошибся — «Отменить» в истории.
- Каждый понедельник после 10:00 МСК бот присылает собственнику: РОПу столько-то за таких-то, лидорубу столько-то за таких-то, кнопки «выплатил». В любой момент — /payouts.
- Считаются только верифицированные оплаты (с чистой суммой); остальные — отдельным списком «Андрею верифицировать». Суммы — как в таблице: каждая строка в целых рублях.
- Учёт выплат стартовал по ведомости на 12.10: всё до 05.10 выплачено всем, с 05.10 МОПам выплачено, РОПу и лидорубу — нет.

## Ссылки на оплату
Т-Банк (31% / 27,5% / 18,9% для 21+), Ресурс развития, Продамус — «Ещё → Ссылки» и «💳 Ссылка» в карточке. Отправил из карточки — при «Оплатил» чистая сама встанет в ведомость по комиссии ссылки. Руководство правит список в приложении.

## План
«Ещё → Настройки → План»: на отдел, на каждого менеджера (₽) и на лидоруба (записей). На «Сегодня» — полоса плана с риской «где должны быть сегодня», прогноз и сколько нужно в день.

## Напоминания
- За **2 часа** — «подтверди встречу», за **1 час** — «через час созвон», за **15 минут** — «напомни клиенту», через 15 минут после начала — «пришёл?» с кнопками ✅ / ❌ НДЗ.
- Через 30 минут после проведённого созвона без отчёта — пинок заполнить отчёт.
- 08:57 МСК — план на день каждому, РОПу и собственнику ещё вчерашний РнП и деньги месяца. 21:00 МСК — РОПу: кто не закрыл день.
- Напоминания приходят только тем, кто хоть раз нажал Start у бота.

## Запуск на Cloudflare (бесплатно)
1. В BotFather создай **нового** бота (например «Команда Рыжикова»), скопируй токен.
2. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Import a repository** → этот репозиторий, ветка с кодом. В настройках сборки **Root directory: `team`**. База D1 создастся сама.
3. В воркере: **Settings → Variables and Secrets → Add → Secret** `BOT_TOKEN`.
4. Проверь в `wrangler.toml`: `OWNER_IDS` (твой Telegram ID) и `APP_URL` (адрес воркера).
5. BotFather → бот → **Bot Settings → Menu Button** → адрес воркера.
6. Открой приложение → **Ещё → Настройки → Выбрать файл history.json** (файл не в репозитории — репозиторий публичный, а там деньги), затем свяжи «Тема», «Дима», «Алексей» из таблиц с людьми.
7. Команда пишет боту `/start` → заявки появляются в «Ещё → Команда», выдаёшь роль в один тап.
